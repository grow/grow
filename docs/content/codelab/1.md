## Install Grow

Grow requires **Python 3.9 – 3.12**. Install it globally with [uv](https://docs.astral.sh/uv/) (recommended) or `pip`:

```bash
# Recommended: install with uv
uv tool install grow

# Or install with pip
pip install grow
```

Verify the installation:

```bash
grow --version
```

You can also view all available subcommands at any time:

```bash
grow --help
```

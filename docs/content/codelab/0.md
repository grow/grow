Welcome to Grow! This short codelab walks through the core concepts of building, localizing, and publishing a static website with Grow in about **10 minutes**.

Grow is built around a simple idea: **configuration over code** for your site's content and architecture. By keeping content in YAML and Markdown, presentation in Jinja2 templates, and URLs in declarative blueprints, Grow makes it straightforward to build sites that are:

- Fast, self-contained static HTML with zero runtime backend
- Cleanly separated between content authors and template developers
- Easy to localize into multiple languages from day one
- Simple to preview locally and deploy to any static host

Let's get started.

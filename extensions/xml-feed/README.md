# XML Feed Extension (`grow-ext-xml-feed`)

Grow extension for importing RSS XML feeds into Grow document collections.
Uses Python's standard library (`urllib.request`, `xml.etree.ElementTree`,
`html.parser`, `email.utils`) with zero extra third-party dependencies.

## Installation

Add to `extensions.txt`:

```text
git+https://github.com/grow/grow.git#subdirectory=extensions/xml-feed
```

# About This Starter

This is a minimal, zero-Node **Grow** starter project.

- Edit `podspec.yaml` to configure locales, routing, and deployments.
- Add YAML or Markdown files under `content/pages/`.
- Customize templates in `views/` and styles in `static/css/main.css`.
